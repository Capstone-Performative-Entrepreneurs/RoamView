Design Rationale

Dark technical UI reduces eye strain during long teleop sessions. Status colors are consistent across all screens. Critical actions (E-stop, export) use high-contrast placement. Information density scales with user role.

View documentation →

UX Design Principles

Role-aware density

Operators see full telemetry and controls. Viewers see read-only dashboards with annotation and measurement tools hidden.

Status at a glance

Consistent badge colors (green=ready/online, amber=processing, red=live/error) across dashboard, sessions, and teleop screens.

Progressive disclosure

3D viewer loads coarse tiles first, then refines. Session list shows thumbnails before full tour. Reports summarize before exporting.
